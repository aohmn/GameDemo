# 0001 — Chuyển định hướng sang game phiêu lưu khám phá và câu cá

- **Bối cảnh**: Game chuyển từ thử nghiệm phố cơ bản sang thể loại phiêu lưu, khám phá đại dương và mô phỏng câu cá thư giãn.
- **Quyết định**: Định hình game xoay quanh trải nghiệm khám phá các vùng biển, câu cá, sưu tập sinh vật biển, nâng cấp trang bị. Mỗi bản đồ câu cá là một module độc lập dùng chung dữ liệu. Chuyển map ban đầu thành đảo bến cảng nhiệt đới quy mô ~50x50m với vịnh tự nhiên, cầu tàu, mặt nước bao quanh và núi che chắn.
- **Hệ quả**: Cập nhật AGENTS.md mục 1. Thay đổi thiết kế map hiện tại và cập nhật tài liệu liên quan mà vẫn giữ nguyên các quy chuẩn kỹ thuật (không texture, shader SDF/vật liệu màu, collision rõ ràng, module độc lập).
